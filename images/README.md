# images

Drop brand assets here.

## book-cover.png (hero)
Save the physical book mockup (the cream "The Year You Were Six" cover) as:

    images/book-cover.png   (or .jpg)

The homepage hero automatically uses it when present, and falls back to the
CSS-rendered book if the file is missing. If you use a .jpg, update the
`src` in index.html (search for `book-cover`).

Recommended: a transparent-background PNG of the book at ~1200px wide.
